/ 01 — how it works

An Enter hook.
Three paths.

dum-tum checks the line you submitted and handles it before the shell reports an unknown command.

  1. 01 └─

    It is a command

    Known commands pass through. Your shell keeps behaving like your shell.

    run normally
  2. 02 └─

    It looks like a typo

    Fuzzy matching happens locally. Safe read-only corrections may run; other corrections ask first.

    local / offline
  3. 03 └─

    It is plain English

    With AI enabled, dum-tum proposes a command. You choose to run, edit, or cancel it.

    AI / confirm

/ 06 — FAQ

Good to know.

More in the README ↗

Does dum-tum run AI commands automatically?

No. AI suggestions always wait for you to press Enter to run, e to edit, or n to cancel. Some safe, read-only typo corrections can run locally without AI.

Do I need an API key?

No. You can use local-only typo handling, or use a supported CLI you already have installed and authenticated. Key-based AI providers are optional.

Which shells and systems work?

dum-tum supports zsh 5+ and Bash 4+ on macOS and Linux. macOS's bundled Bash 3.2 supports local typo handling, but needs a newer Bash or zsh for the full Enter hook.

What does AI mode send?

AI mode sends your request plus shell context such as your OS, current directory, some directory entries, aliases, and project commands. Read the safety notes before using AI with sensitive work.
